# 🎵 Music Player – Web Application

A Modern, Intractive and Responsive Music Player

## 📌 Project Overview

The Music Player is a modern and user-friendly web application developed using HTML, CSS, and JavaScript. It allows users to enjoy their favourite music through an interactive and visually attractive interface.

The application provides essential music playback functionalities, including play, pause, next, previous, volume control, and music progress tracking. It is designed with an attractive user interface to provide a smooth and enjoyable listening experience.

This project was developed as part of the **CodeAlpha Internship Program** to gain practical experience in frontend web development and JavaScript programming.

---

## 🚀 Key Features

- 🎧 Play and Pause Music – Control music playback easily.
- ⏭️ Next Track – Move to the next song.
- ⏮️ Previous Track – Play the previous song.
- 📜 Playlist Management – Display and select available songs.
- 🎚️ Volume Control – Adjust the music volume.
- ⏱️ Progress Bar – Track the current playback position.
- 🔊 Audio Controls – Control audio playback.
- 🎨 Attractive User Interface – Modern and visually appealing design.
- 📱 Responsive Design – User-friendly layout for different screen sizes.

## 🎮 How to Use

1. Open the Music Player application.
2. Select a song from the available playlist.
3. Click the Play button to start playing music.
4. Use the Pause button to stop playback temporarily.
5. Use Next and Previous buttons to change tracks.
6. Adjust the volume using the volume control.
7. Track the song duration using the progress bar.
