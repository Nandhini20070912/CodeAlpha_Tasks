
# CodeAlpha Music Player

## Project Overview
Tamil Melody Music Player is a web-based
music player that allows users to explore
and listen to Tamil songs.

## Features
- Latest Tamil music playlist
- Spotify embedded music player
- Responsive design
- Attractive user interface
- Easy music playback

## Technologies Used
- HTML
- CSS
- JavaScript
- Spotify Embed

## How to Run
1. Open the project in VS Code.
2. Open index.html.
3. Run using Live Server.
4. Internet connection is required.
5. Play songs using the Spotify player.
