# Personal Portfolio Website

## Project Overview
A professional and responsive personal portfolio website developed as part of the CodeAlpha Frontend Development Internship.

This website showcases my personal introduction, technical skills, educational background, projects, certificates and contact information.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Professional home page
- About Me section
- Technical skills section
- Education details
- Project showcase
- Certificates and achievements
- Contact form
- Responsive mobile layout
- Interactive navigation menu
- Smooth scrolling
- Modern purple and white design

## Project Structure
```text
CodeAlpha_Portfolio/
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html.
4. Run the project using Live Server.
5. View the portfolio in your browser.
