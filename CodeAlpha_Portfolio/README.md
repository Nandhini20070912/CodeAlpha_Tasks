# 💼 Personal Portfolio Website

  A Creative and Professional Personal Portfolio.
  Showcasing My Skills, Projects, Education and Achievements.
---

## 📌 Project Overview

The Personal Portfolio Website is a responsive and visually attractive web application developed to showcase my technical skills, academic background, projects, certifications and professional achievements.

This portfolio serves as a digital platform to introduce myself, highlight my development journey and demonstrate my practical knowledge in web development.

The website is designed with a clean layout, attractive colours, smooth navigation and a user-friendly interface to provide visitors with a professional browsing experience.

This project is developed as part of the **CodeAlpha Internship Program** to enhance my frontend development skills and gain practical experience in building real-world web applications.

---

## 🎯 Objectives

- Build a professional online presence.
- Showcase technical skills and projects.
- Present academic and professional achievements.
- Improve frontend development knowledge.
- Create a responsive and user-friendly website.

## ✨ Key Features

- 🏠 **Home Section** – Introduction and personal profile.
- 👩‍💻 **About Me** – Information about my background and interests.
