
# ✨ Basic Calculator

## 📌 About the Project
The Basic Calculator is a simple and user-friendly web application developed using HTML, CSS, and JavaScript. It performs basic mathematical operations with an attractive and colourful user interface.

## 🎯 Objective
The main objective of this project is to develop a simple calculator that helps users perform mathematical calculations quickly and easily.

## 🚀 Features
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Clear (AC) and Delete (DEL) options
- Calculation History
- Clear History option
- Attractive Purple and Pink Gradient Design
- Responsive User Interface

## 🛠️ Technologies Used
- **HTML5** – Creates the structure of the calculator.
- **CSS3** – Provides styling, colours, layouts and animations.
- **JavaScript** – Handles calculations and user interactions.

## 📂 Project Structure

Basic_Calculator/

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all four files are in the same folder.
4. Open `index.html` in your web browser.
5. Start performing calculations.
