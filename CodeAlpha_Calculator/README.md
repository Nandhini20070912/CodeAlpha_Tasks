# 🧮 Basic Calculator – Web Application

## 📌 Project Overview

The Basic Calculator is a simple and interactive web application developed using HTML, CSS, and JavaScript. It allows users to perform basic mathematical operations such as addition, subtraction, multiplication, and division.

The application provides an attractive and user-friendly interface with a beautiful purple and pink gradient design. It also includes calculation history, clear and delete options to make calculations easier and more convenient.

This project is developed to improve practical knowledge of frontend web development and JavaScript programming.

---

## 🚀 Features

- ➕ Addition of two numbers
- ➖ Subtraction of numbers
- ✖️ Multiplication operation
- ➗ Division operation
- 📊 Percentage calculation
- 🔄 Clear (AC) and Delete (DEL) options
- 📜 Calculation history tracking
- 🗑️ Clear history option
- 🎨 Attractive purple and pink gradient interface
- ✨ Interactive calculator buttons
- 📱 Responsive user interface

---

## 🛠️ Technologies Used

- **HTML5** – To create the structure of the calculator.
- **CSS3** – To design the layout, colours, buttons and visual   effects.
- **JavaScript** – To perform mathematical calculations and handle user interactions.

## 💡 How It Works

1. Enter numbers using the calculator buttons.
2. Select the required mathematical operator.
3. Enter the next number.
4. Click the equals (=) button to display the result.
5. View previous calculations in the history section.
6. Use AC to clear the display and DEL to remove the last character.
