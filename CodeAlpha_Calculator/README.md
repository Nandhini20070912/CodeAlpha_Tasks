
# CodeAlpha Calculator

## Project Overview
This project is a simple and responsive Calculator developed as part of the CodeAlpha Frontend Development Internship.

It performs basic mathematical operations using HTML, CSS, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear button
- Delete button
- Real-time calculation
- Simple and user-friendly interface

## Project Structure
```text
CodeAlpha_Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using Live Server.
5. Use the calculator to perform mathematical operations.

## Learning Outcomes
- Understanding HTML structure.
- Styling webpages using CSS.
- Implementing JavaScript functions.
- Handling button clicks and user input.
